# Cutout development resources

## Knowledge

- [FastAPI: Request Files](https://fastapi.tiangolo.com/tutorial/request-files/)
  Official guide to `UploadFile`, multipart form requests, and async file reads. Use when working on the upload endpoint.
- [MDN: Using FormData Objects](https://developer.mozilla.org/en-US/docs/Web/API/XMLHttpRequest_API/Using_FormData_Objects)
  Explains how a browser sends a file with `fetch`. Use when tracing or changing the frontend request.
- [MDN: URL.createObjectURL](https://developer.mozilla.org/en-US/docs/Web/API/URL/createObjectURL_static)
  Explains temporary browser URLs for blobs. Use when handling preview and download URLs.
- [MDN: CSS custom properties](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascading_variables/Using_custom_properties)
  Explains values such as `--split`, which drives the before/after slider.

## Wisdom

- [FastAPI GitHub Discussions](https://github.com/fastapi/fastapi/discussions)
  Use for framework-specific patterns after reading the official documentation.
- [Hugging Face Forums](https://discuss.huggingface.co/)
  Use for model-loading and inference issues after isolating a reproducible example.
