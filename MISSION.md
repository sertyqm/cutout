# Mission: Build and understand Cutout

## Why
Build a credible computer-vision portfolio project that removes image backgrounds, while learning to direct and review AI-assisted development instead of blindly accepting generated code. The result should be a project you can explain confidently to a client or interviewer.

## Success looks like
- Run Cutout locally, explain every request and image transformation in its upload flow, and diagnose basic failures.
- Evaluate the selected model on difficult real images and make evidence-based quality decisions.
- Publish a clear, honest GitHub portfolio project with a working demo path.

## Constraints
- Learn through short practical tasks; write and run changes personally, with the agent acting as teacher and reviewer.
- Avoid unsupported claims about quality, privacy, or commercial-service parity.

## Out of scope
- Training a foundation segmentation model from scratch.
- Pretending an untested result is production-ready.
